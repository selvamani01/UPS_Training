# Day 4 – Java Training

1. **GradeSystem.java**
   - **Question:** Assign a grade based on the student's marks.
   - **Concept:** Switch-case, if-else.

2. **calculator.java**
   - **Question:** Perform arithmetic operations using a calculator.
   - **Concept:** Switch-case, operators.

3. **divisibleby3.java**
   - **Question:** Check whether a number is divisible by 3.
   - **Concept:** If-else, modulus operator.

4. **nestedloop.java**
   - **Question:** Print patterns using nested loops.
   - **Concept:** Nested loops.

5. **switchcase.java**
   - **Question:** Display the day of the week based on a number (1–7).
   - **Concept:** Switch-case, break statement.
