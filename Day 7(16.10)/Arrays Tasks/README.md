# Day 7 – Java Training

### Array Programs

1. **arraycount.java**
   - **Question:** Count the number of odd, even, and prime numbers in an array.
   - **Concept:** Arrays, loops, if-else, modulus operator, prime number checking.

2. **arrayinput.java**
   - **Question:** Accept and display array elements using user input.
   - **Concept:** Arrays, Scanner, loops.

3. **arraylen.java**
   - **Question:** Find the length of an array.
   - **Concept:** Arrays, `length` property.

4. **comparearrays.java**
   - **Question:** Compare two arrays.
   - **Concept:** Arrays, loops, conditional statements.

5. **copyarray.java**
   - **Question:** Copy elements from one array to another.
   - **Concept:** Arrays, loops.

6. **jaggedarray.java**
   - **Question:** Calculate the total marks of each student using a jagged array.
   - **Concept:** Jagged arrays, nested loops, two-dimensional arrays.

**Language:** Java
