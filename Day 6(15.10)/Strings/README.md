# Day 6 – Java Training

### String and Number Programs

1. **ArmstrongNumber.java**
   - **Question:** Check whether a number is an Armstrong number.
   - **Concept:** Loops, arithmetic operators, if-else.

2. **Factorial.java**
   - **Question:** Find the factorial of a number.
   - **Concept:** Loops, multiplication.

3. **FibonacciSeries.java**
   - **Question:** Print the Fibonacci series.
   - **Concept:** Loops, variables.

4. **PalindromeString.java**
   - **Question:** Check whether a string is a palindrome.
   - **Concept:** Strings, loops, conditional statements.

5. **PrimeNumber.java**
   - **Question:** Check whether a number is prime.
   - **Concept:** For loop, if-else, Boolean variable, modulus operator.

**Language:** Java
