# Day 5 – Java Training

### Alphabet Pattern Printing (A–Z)

- **Question:** Write a Java program to print an uppercase alphabet pattern based on the user's input (A–Z) and the specified size.
- **Concepts Used:**
  - Nested `for` loops
  - `if-else-if` statements
  - Logical operators (`&&`, `||`)
  - Character input using `Scanner`
  - Pattern printing using stars (`*`) and spaces

- **Language:** Java
- **File:** `PatternAtoZ.java`
